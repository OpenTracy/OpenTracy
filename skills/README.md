# skills/ — foundation 2: Skills (content plane)

Each skill is a directory with a `SKILL.md` (frontmatter: name, description, triggers,
required tools) plus any bundled resources (templates, scripts, reference docs).

- `core/` — generic procedures: research, summarize-and-cite, self-review
- `sharpi/` — domain procedures: match-correction triage, automated research flows

Progressive disclosure: only name + description enter session context; the body loads
when the skill activates. Contract spec: `docs/adr/` (Phase 0).
